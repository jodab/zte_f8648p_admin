ZTE F8648P password recovery

Recover the admin password from a ZTE ZXHN F8648P config.bin backup.

Runs entirely in your browser. Your config file, MAC, serial and the recovered password are processed locally and never sent anywhere. No network requests, no dependencies — you can disconnect from the internet and it still works.
How it works & requirements

The backup is an AES-256-CBC + zlib container whose key is derived from the device's own MAC and serial:

key = SHA256( serial[4:12].upper() + reverse(mac octets).lower() )
iv  = SHA256("ZTE%FN$GponNJ025")[:16]

Because the key is tied to hardware whose label you must physically read, this is a recovery tool for a device you own. Tested on F8648P firmware V2.0.12P1N22 / N28 / N29.

Needs a browser with DecompressionStream (Chrome/Edge 80+, Firefox 113+, Safari 16.4+) and Web Crypto.
